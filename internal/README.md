# Internal working material

Private design and reference material for Propolis: the architecture overview, the ADRs, the
per-sub-project design specs, the security and compliance posture, the roadmap, and the
reverse-engineered reference for the prior system.

This directory is NOT part of the public repository. The design docs here are working drafts;
public documentation is authored separately. When Propolis is published, the public repo is
created from a fresh history containing only the public-facing files (README, LICENSE, the
source, and any human-authored docs). Nothing under `internal/` is pushed to the public repo.
