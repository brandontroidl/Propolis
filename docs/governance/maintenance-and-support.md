# Maintenance and support

## Maintenance model

Propolis is a single-maintainer, source-available project. It is actively
developed but carries no organization, no support desk, and no paid tier.
Maintenance is **best-effort**: issues, fixes, and releases happen as the
maintainer's time allows, with no committed cadence.

## Support expectations

- **No SLA.** There is no response-time or resolution guarantee for issues,
  questions, or security reports.
- **No warranty.** Use is governed by the license; see
  [licensing.md](licensing.md) and the disclaimer in
  [`LICENSE.md`](../../LICENSE.md).
- **Best-effort security handling.** Report vulnerabilities through the process
  in [../security/vulnerability-disclosure.md](../security/vulnerability-disclosure.md);
  triage and fixes are best-effort, on the same solo-maintainer basis.

## Getting help

- Read the corpus first: start from [../../DOCUMENTATION.md](../../DOCUMENTATION.md)
  or the audience manuals under [../manuals/](../manuals/).
- For defects and questions, use the project's GitHub repository (issues /
  discussions).

## Contributing

Noncommercial contributions are welcome under the project's license. See
[contribution.md](contribution.md) for the PR flow, the merge gate, and the
contribution terms.
